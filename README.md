## ☕ About the Project
Welcome to the **Campus Cafe System** repository! This project is built to streamline campus coffee shop operations, handling ordering, inventory tracking, and student transactions seamlessly.

---

## ✨ Key Features
* 🛒 **Order Management:** Easily process customer orders and track order statuses.
* 📦 **Inventory Tracking:** Monitor stock levels for ingredients and cafe supplies.
* 📊 **Sales Reporting:** Generate daily and weekly transaction summaries.
* 💻 **User-Friendly Interface:** Built with efficiency and simplicity in mind for campus staff.

---

## 🚀 Tech Stack
* **Language:** Java
* **IDE:** IntelliJ IDEA (`.idea` configuration included)
* **Version Control:** Git & GitHub
